## 📖 作家介绍与艺术生平

乔普林出生于美国德克萨斯州，在非裔民间切分音乐传统与欧洲古典钢琴技术的交汇中开创了风靡全球的‘拉格泰姆’（Ragtime）风格。乔普林的钢琴作品旋律欢快跳跃、节奏富于弹性与律动感，同时蕴含细腻典雅的古典结构美。代表作《枫叶拉格》与《演艺人》（电影《骗中骗》主题曲）是全世界家喻户晓的经典名作。
