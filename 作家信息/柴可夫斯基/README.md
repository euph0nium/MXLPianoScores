## 📖 作家介绍与艺术生平

柴可夫斯基毕业于圣彼得堡音乐学院，将俄罗斯民族民间音乐的深沉忧郁、辽阔奔放与西欧古典管弦乐交响构思完美融为一体。柴可夫斯基拥有无与伦比的抒情旋律天赋。其创作的《儿童钢琴曲集 Op.39》（全24首）生动再现了俄罗斯儿童的日常生活、童话故事与异国风情（如《晨祷》、《玩具兵进行曲》、《甜美的梦》、《俄罗斯舞曲》等），曲调通俗优美、形象生动，深受全世界钢琴演奏者喜爱。
