## 📖 作家介绍与艺术生平

格里格毕业于莱比锡音乐学院，随后致力于发掘挪威民间传说、民歌调式与峡湾壮丽自然风光中的艺术灵感。他的音乐清新纯净、和声大胆新颖，对后来的印象主义音乐产生了先导性启示。格里格一生共创作了 10 卷共 66 首《抒情小品集》(Lyric Pieces)，包括著名的《致春天》、《蝴蝶》、《特罗尔德豪根的婚礼日》、《挪威舞曲》等，将北欧大自然的纯净风情化作极度洗练优美的钢琴音诗。
