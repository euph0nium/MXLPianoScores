## 📖 作家介绍与艺术生平

库劳早年在汉堡学习音乐，后定居哥本哈根并成为丹麦宫廷作曲家。他曾与贝多芬私交甚笃并深受其启发。库劳的小奏鸣曲（如 Op.20、Op.55、Op.59）旋律活泼纯净、技术难度适中、曲式严谨清晰，充满歌唱性的欢快主题，是钢琴学子从初级进阶到中高级古典奏鸣曲不可或缺的基石文献。
