## 📖 作家介绍与艺术生平

拜厄活跃于19世纪中叶的德国莱茵地区，致力于普及钢琴基础教育。他编订的《钢琴初级教程 Op.101》以极其平缓温和的坡度，系统讲解了五线谱识读、双手独立协调、简单调性转换、音阶与琶音练习，并穿插了大量优美易懂的四手联弹曲目。历经一个半世纪的教学检验，拜厄教程依然是全球非专业与少儿钢琴启蒙最具知名度的入门大纲之一。
