## 📖 作家介绍与艺术生平

克莱门蒂出生于罗马，长期活跃于伦敦。他是最早完全针对现代击弦钢琴（而非羽管键琴）的机械性能与发音特质进行系统创作和演奏的先驱。曾与青年莫扎特在维也纳宫廷进行举世瞩目的钢琴演奏对决。他的《6首小奏鸣曲 Op.36》结构紧凑明快、乐句清晰匀称、指法规范严谨，是所有学习古典奏鸣曲结构与双手平衡控制最重要的必修阶梯。
