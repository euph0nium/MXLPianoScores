## 📖 作家介绍与艺术生平

勃拉姆斯出生于汉堡，青年时期受到舒曼夫妇的大力推介。在19世纪激进的新德意志乐派狂潮中，勃拉姆斯坚持严格继承巴赫的对位法与贝多芬的古典奏鸣曲严密架构，创造出宏大雄浑与深沉内敛并存的崇高艺术风格。他的晚期钢琴小品集（Op.116至119间奏曲、狂想曲、叙事曲）被誉为‘写给钢琴的暮年沉思诗篇’。
