## 📖 作家介绍与艺术生平

莫扎特出生于奥地利萨尔茨堡，4岁开始作曲，自幼随父亲巡演全欧，展现出震古烁今的音乐早慧。在短暂而辉煌的35年生命中，莫扎特留下了600多部涵盖所有体裁的旷世杰作。莫扎特的钢琴作品结构严谨对称、织体明澈透亮，看似清丽流畅、无拘无束，实则蕴含极高的歌唱性与细腻复杂的情感张力。他的音乐被后世誉为‘降临人间的纯净阳光’。
